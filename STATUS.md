# Project status

- **Name:** Solphivia Avatar AI
- **Version in source:** 0.8.9 (`versionCode 25`)
- **Distribution:** community alpha source; not published on Google Play
- **Android configuration:** compile/target API 35, JDK 17, Android Gradle Plugin 8.9.1
- **Verification:** the latest source edits have not been rebuilt or tested on a physical device

The app currently contains an animated Android overlay and chat, touch-driven avatar controls, speech output and recognition, document/image selection, local conversation history, and an optional Sign in with ChatGPT connection. See the README for limitations and privacy behavior.

The next release gate is a verified Android build, device testing, provider boundary design, and completion of the Google Play privacy, AI-response reporting, and foreground-service requirements.

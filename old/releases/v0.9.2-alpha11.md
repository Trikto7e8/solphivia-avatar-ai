# Solphivia Mobile 0.9.2-alpha11 — Parliamo, naturalmente.

![Solphivia alpha11 promotional cover](../media/solphivia-alpha11-cover.png)

24 October 2026 · Android community alpha · versionCode 44 · debug-signed test build.

Alpha11 combines the merged Stage A provider work from [PR #16](https://github.com/Trikto7e8/solphivia-avatar-ai/pull/16), the previously local alpha10 device commands, and the voice conversation improvements validated with the maintainer. Thank you to Sandeep (@sunny-kavixo) for the provider architecture and follow-up fixes.

## What changed

- Say “Hola Solphivia”, ask a question and continue with an ordinary reply within five seconds of microphone readiness after the answer. Silence returns to local wake waiting; a phrase started in time may finish after the window. There is no spoken announcement of the timer.
- Speech appears in the typed chat input before automatic submission. Partial preview depends on Android recognition support. Typed drafts and manual edits are preserved.
- Local app opening by exact label, Maps searches/directions, camera/phone opening and dialer preparation. Calls require manual confirmation; no direct calling or contact access is added.
- Immutable provider requests, single-use memory consent bound to SHA-256 attachment content, malformed avatar-control filtering and separate voice phase labels from the merged Stage A work. No configurable Ollama/LM Studio adapter or automatic local-to-cloud fallback is introduced.
- Clear “PROVA” labels for isolated builds. The standard package remains `it.solphivia.mobile`; the new isolated build uses `it.solphivia.mobile.alpha11.verification`.

## Verification — automated

- **38 JVM tests pass**, no failures/errors: 30 from the provider slice, 2 independent regression cases and 6 follow-up timing tests.
- App and instrumentation APK builds pass. Android Lint: **0 errors, 118 warnings**.
- Four isolated suites pass on Moto g35 5G, Android 16/API 36: memory/vault and overlay regression; local command and intercepted-intent checks; follow-up timing and wake decisions; transcript composer, partial callbacks and manual draft protection.
- The general regression includes a live DPC data scan and is not entirely offline. Command tests intercept intents: they do not actually place calls or launch third-party apps. Timing/transcript probes use synthetic state and input fields, not live ASR or account credentials.
- CI verifies unit tests, APK builds and lint; it does not replace connected-device or account testing.

## Verification — manual

The maintainer confirms visible transcription and continued conversation on the final alpha11 installed in the main package. This user-reported result is distinct from the automated suites. The update preserved the existing encrypted memory file and stored ChatGPT connection preferences; no uninstall or data reset was used.

This does not certify exact wall-clock timing, long-running stability, every consent interaction, network interruption recovery, locked-screen/background behavior or other devices. Earlier manual observations with identically named installations were ambiguous; they are not used as proof of a remaining defect in PR #16.

## Install or update

Download `SolphiviaMobile-0.9.2-alpha11.apk` from this release. Android 8+ (min API 26), ARM64/ARMv7; target/compile SDK 35. This is not a Google Play release. Use an update over an existing app with the same certificate; do not uninstall merely to update, as uninstalling removes local data and Keystore-backed access. Different signing certificates cannot update each other.

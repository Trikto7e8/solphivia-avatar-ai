# Solphivia Mobile 0.9.2-alpha9 — Hola Solphivia, hands free

> Historical release / Release storica. Current version: [alpha11 (44)](../../docs/CURRENT_RELEASE.md) — [download](https://github.com/Trikto7e8/solphivia-avatar-ai/releases/tag/v0.9.2-alpha11). The original release description and test evidence below are preserved.

Say **«Hola Solphivia»**, wait for **«Cosa posso fare per te?»**, then ask a question or say **«apri WhatsApp»**. The voice request is sent automatically; no manual memory confirmation interrupts it.

Community Android alpha, debug-signed for testing. Not a app stores release. Update over alpha4/alpha5 with the same signing certificate; no uninstall or data reset needed. APK includes the Italian wake model, so it is larger than previous builds. ARM64 and ARMv7 only; not an x86 emulator build.

## What changed

- Local Italian Vosk listening for the greeting, with Android command recognition opened only after the spoken response. This avoids repeatedly opening and closing Android recognition during wake waiting.
- The selected Android TTS voice, contextual outfits and sitting/sleep animations remain available. The floating avatar hides while the internal chat is visible.
- Explicit WhatsApp opening is handled locally, without an AI request. Normal WhatsApp is preferred, with Business as fallback. No contact reading, message reading or sending.
- Voice questions use the connected provider and recent text history automatically, without adding personal vault memory or attachment payloads. Typed requests keep the separate, editable memory confirmation. Single-phrase editable dictation remains a draft.
- Foreground microphone service, recovery requested after an Android process termination, Stop dialog and microphone-off controls. No microphone start at phone boot.
- Optional local greeting calibration stores text variants, not audio recordings. More robust reuse of animation bitmaps.

This release replaces the previous experimental Voice Access implementation with the path tested on the phone. The alpha5 ShareBridge sharing preview is not active in alpha9; only WhatsApp opening is supported. Earlier source remains in its existing release tag. Thanks to contributors for the earlier Voice Access and Android readiness groundwork.

## Try it

1. Install the APK, allow overlay and microphone, and open Solphivia. The active microphone has an Android notification.
2. Wait for the opening greeting to finish. Say «Hola Solphivia» and wait for «Cosa posso fare per te?».
3. Say «apri WhatsApp», or ask a short question. Other app actions are not generally supported.
4. Use Stop dialogo to return to wake waiting; Spegni microfono stops capture. Reopening the app starts it again if automatic wake is enabled.
5. If Android restricts background capture, allow background use for Solphivia. Some Motorola phones also have app standby and lock-screen app-stop settings. Change only the settings you choose for this app.

## Privacy and limits

Wake audio is processed locally without saving recordings. Android command recognition and the selected TTS engine may use the network according to their settings. AI questions send text and recent text chat history to the configured provider; they do not automatically attach personal vault memory or files. This does not make the whole conversation offline. The avatar does not read screens or automate touches in other apps.

The maintainer's device test confirmed wake, the spoken response, WhatsApp opening and automatic request submission. Isolated instrumentation checked command parsing, file exclusion and typed memory consent; build and Android Lint passed. Microphone recovery after controlled process termination and explicit shutdown were tested. Results on one Motorola do not establish reliability on other devices, during screen lock, in noise, or over long battery sessions.

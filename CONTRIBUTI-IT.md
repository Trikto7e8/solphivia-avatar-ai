# Contribuire a Solphivia Avatar AI

Grazie per l'interesse a contribuire. Il repository contiene l’alpha11 Android corrente ([versione e collaudo](docs/CURRENT_RELEASE.md)); prima di proporre modifiche importanti, apri una segnalazione così possiamo concordarne l'ambito.

## Ambito

- Il codice sorgente del software è distribuito con licenza MIT.
- Personaggio, volto, animazioni, abiti e identità visiva di Solphivia sono riservati; consulta `ASSETS-LICENSE.md` o `LICENZA-ASSET-IT.md`.
- Non inserire chiavi API, token OAuth, dati personali, schermate private o credenziali nelle segnalazioni e nelle pull request.
- Mantieni le azioni dell'IA sotto il controllo dell'utente e limitate ai comandi avatar esplicitamente supportati.

## Pull request

1. Descrivi il problema visibile all'utente e il comportamento introdotto dalla modifica.
2. Mantieni la modifica circoscritta e includi i passaggi per riprodurla e verificarla.
3. Quando possibile, compila e prova su un dispositivo Android o un emulatore; indica cosa non hai potuto provare.
4. Non includere output di compilazione generato (`build/`, APK, AAB o chiavi di firma) nelle pull request del codice sorgente.

## Find a first contribution

See [COLLABORATE.md](COLLABORATE.md) for Android, iOS, local-model and testing requests. Use a GitHub noreply commit email; examples must contain synthetic data only.
